# Créditos e autorização de publicação

O IAgroTech foi desenvolvido de forma colaborativa durante um hackathon. Esta versão demonstrativa deriva daquele trabalho e não reivindica autoria individual sobre o produto ou sobre contribuições de outros participantes.

Antes de tornar este repositório público, confirme com a equipe e/ou organização do hackathon que a cópia e a redistribuição dos arquivos estão autorizadas. Confirme também qual licença foi efetivamente acordada para o projeto e inclua o arquivo de licença correspondente. O ZIP de origem recebido para esta adaptação não continha um arquivo `LICENSE`; por isso, nenhuma licença foi presumida ou adicionada.

## Contribuições nesta versão demonstrativa

- Preparação de uma versão de frontend para portfólio, com acesso sem cadastro.
- Substituição das chamadas de dados por serviços locais e dados fictícios.
- Persistência isolada no `localStorage` de cada navegador.
- Documentação do escopo e das limitações da demonstração.
